## Q1: What to do if you encounter an unknown problem?

<mark class="orange">A better way is to extract the application run log and send it to the group.</mark>

### Log Extraction Method

Computer users can update to version 1.0.1 or later and open it directly in the settings, or you can find it yourself from the following locations:

Android: Directly select AstroBox in the native file app (you can use tools like MT to search for and open the native file, and switch to the AstroBox tab in the upper left corner, where the Logs folder is what we need).

Windows:

> C:\Users\Your_Username\AppData\Local\moe.astralsight.astrobox

Mac:

> /Users/Your_Username/Library (or translated as Resources, requires shortcut command+shift+. to appear)/Logs/moe.astralsight.astrobox/

Linux:

> /home/Your_Username/.local/share/moe.astralsight.astrobox/

### Config Storage Location

Windows:

> C:\Users\Username\AppData\Roaming\moe.astralsight.astrobox

Mac:

> /Users/Username/Library/Application Support/moe.astralsight.astrobox
